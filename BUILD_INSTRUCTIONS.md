## Running the Application (H5 / Web Preview)

These commands start a local development server, allowing you to preview the application in a web browser. The H5 build is generally the quickest way to see visual output.

Choose one of the following commands:

*   **Using npm:**
    ```bash
    npm run dev:h5
    ```
*   **Using pnpm:**
    ```bash
    pnpm dev:h5
    ```
*   **Using yarn:**
    ```bash
    yarn dev:h5
    ```

After running the command, you should see output in your terminal indicating that the development server is running, typically something like:
```
App running at:
- Local:   http://localhost:3000/  (or another port like 8080)
- Network: http://<your-ip-address>:3000/
```
Your default web browser might open automatically. If not, navigate to the provided local URL in your browser.
